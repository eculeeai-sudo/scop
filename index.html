시험모드 선택 (분석모드 → 시험항목 → 시험조건)

시험 항목을 선택하면 관련된 채널만 자동으로 ON 되고, 현대GSW 실차파형 특성을 반영한 신호가 즉시 출력됩니다. 아래 채널 카드에서 세부값을 추가로 조정할 수 있습니다.
~
연속: 선택한 시험조건 파형을 계속 출력합니다. 자동: 설정한 주기마다(주기 변동폭 또는 최소~최대 범위를 주면 매번 다른 간격으로 불규칙하게) 시험조건 파형을 1회씩 발생시키고, 횟수만큼 발생하면 대기 상태로 돌아갑니다. 수동: [파형 발생] 버튼을 누를 때마다 1회 발생합니다(횟수 제한 가능). 발생하지 않는 동안에는 대기 상태(KEY ON/OFF) 파형이 출력됩니다. 자동은 RUN을 누를 때마다 처음부터 다시 시작됩니다.
체크한 파형이 A→B→C→D 순서로 채널에 자동 배정됩니다. 각 파형마다 유니폴라/바이폴라 극성을 개별 선택할 수 있고, 아래 채널 카드에서 전압범위·주파수·듀티를 추가로 조정할 수 있습니다.

엔진 RPM 일괄 설정 (A·B·C 채널)

A·B·C 채널에 같은 엔진 회전수가 일괄 적용됩니다. 값을 바꾸면 즉시 반영되며 학생 모드 화면에도 함께 전송됩니다.

CVVT (연속가변밸브타이밍) 작동

CVVT 정지: 흡기 0.0°CA / 배기 0.0°CA / 크랭크 0.0°CA
작동을 켜면 ICMP(흡기캠)는 진각, ECMP(배기캠)는 지각 방향으로 설정한 각도만큼 서서히 이동하여 CKP(크랭크) 결손부 기준 캠 엣지 위치가 달라지고, 크랭크축(CKP) 파형도 설정한 각도만큼 위치가 이동합니다(1°CA = 크랭크 1° = 캠 0.5°). 끄면 기준 위치로 복귀합니다. 학생 모드 화면에도 함께 전송됩니다.

수학모델 설정 (A·B 채널 연산 → M채널)

연산을 선택하면 A·B 채널 신호를 계산한 결과가 M채널(주황색)로 화면에 추가 표시됩니다. A·B 채널이 OFF여도 두 채널의 신호원으로 계산됩니다. 교수/학생 모드 모두 우측 M채널 카드에서 ON/OFF·연산·Volts/DIV·위치를 조정할 수 있습니다.

채널별 가상 신호 소스 설정
